# Party Character Sheet

Live wrapper for the same 9:16 eight-panel guest card.

## Guest URL

After Pages is on:

https://geollama.github.io/party-character-sheet/

## Turn Pages on (one time)

1. Open https://github.com/geoLlama/party-character-sheet/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main** / **/** (root)
4. Save

Wait a minute, then open the guest URL in Chrome. The page draws its own QR.
